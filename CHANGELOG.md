# Changelog

Full history of Borehole Geology Sections (metadata.txt keeps only the latest versions).

- 0.27.18 - fixed: the pattern colour helpers (line_is_light, _recolor, LIGHT_LINE) were missing in patterns.py since 0.27.15, so drawing any lithologic pattern ended with a NameError - restored; the message about too many cells of the smooth model shows the limit (a missing f before the text); section edits: an unknown state of a forced link is refused, a lens with the tips in reverse order is turned the right way, apply_shift tolerates a contact of less than two points; 3D viewer: the texture filter without tiles, a clearer name in the copy of a fault
- 0.27.17 - changed: the option 'Coordinates are given without minus sign' was removed from the Data tab - S-JTSK coordinates are made negative automatically (EPSG:5514 has both coordinates negative everywhere, so a positive value is only a missing sign); the log reports how many boreholes got the sign; 3D model tab: the groups A) Fence model and B) Full model fold away (opening one folds the other, only A) is open at first)
- 0.27.16 - fixed: the columns X, Y (also E / N, lon / lat) and Layer to [m] are preselected on the Data tab when the heading of the CSV column contains the wanted word (e.g. 'X (northing, latitude)', 'Layer to [m]'); until now the short keywords (x, y, to, do, e, n) matched only a column that was named exactly so and the first column was taken
- 0.27.15 - changed: all pattern tiles are black now (901 soil and 902 dirt were light) - the light variant for dark colours is made by the plugin from them; fixes: names of boreholes and lithologies lose control characters (a saved file of section edits could not be loaded again); the section edits are written through a new unpredictably named file in the same folder; undo history of the section editor is limited to 100 steps; only the file made by the plugin is opened in the web browser; 3D viewer: the cache of surface heights under a dragged fault is limited; pattern cache is LRU; 3D layers report a provider that refuses the features; a damaged age of a layer no longer breaks the stratigraphic column colours; the preview of a CSV file reads as many characters as bytes; removed: the unused functions with_faults and sanitize_faults
- 0.27.14 - changed: lithologic patterns have two colour variants - black lines (as in the FGDC standard), or pale cream ones on a dark colour of the lithology (coal, soil, dirt, peat, dark clay...); the variant is chosen automatically from the luminance of the lithology colour, the same in the 2D sections, borehole logs, legends and the 3D viewer; the tiles 901 (soil) and 902 (dirt) follow the same rule instead of always having light lines; README corrected
- 0.27.13 - added: 3D viewer, panel Faults - Export faults / Import faults (JSON file), so faults added in a web browser are not lost with the tab and can be carried to another model; changed: removing the overlaps of 2D section polygons subtracts only the neighbouring polygons (much faster for long sections); removed: the unused embedded 3D window (Viewer3DWindow, QtWebEngine code) - the viewer opens in the web browser as before; README corrected
